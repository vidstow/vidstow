A new Home, from the one we ship

Orange is Home on main Green is the new p2

This page is Home-only. The full paper-to-p2 pass, including Queue, Downloads, and Settings, lives on paper-to-p2.html. Orange here is the Home we ship. Green is a new Home I would build next.

The new design takes the compact dock and the idea that the paste decides video, playlist, or batch. It keeps the honesty main already paid for: a folder you can change, a review that names bad lines, and a list that can use the leftover pane.

  • One field
  • Paste decides
  • Compact dock
  • Coverage line
  • Pin after Analyze
  • Start N, not Admit

Keep from Home

Change… stays on the save bar. Playlist range, search, and the 500 cap stay. Batch lines still say Ready, Duplicate, Invalid, or Analysis failed. A watch URL that also has a playlist still asks which to review. Subtitles, extra .srt, and title and channel extras stay in the disclosure, not in Settings only.

Leave on main

The Batch URLs toggle and the second textarea are the wrong model once one field can hold several links. The Choose Download column and the always-open radio list make a single video feel like a form. The empty glyph is a dead landing. It does not teach the paste.

1. Empty Home should teach the paste

Shipped Home pins a URL strip to the top and leaves a download glyph in the middle. The only sentence is Paste a YouTube URL to analyze. That is accurate and also mute. A first-time window looks unfinished rather than ready.

The new p2 treats empty Home as a landing. The field sits in the optical middle because it is the only object on the page. A short line under it says the paste can be one video, a playlist, or several links. Dotted try-chips fill the field so someone can see the three shapes without reading a manual.

The placeholder can stay plain: Paste a YouTube URL. The watch-URL example on main is precise and also looks like a leftover. A ⌘L chip belongs in the field once shortcuts exist. Until then the chip can wait.

2. Kill the Batch URLs toggle

Main keeps single-URL mode as the default and hides a second composer behind a list icon. That was the right compromise when batch shipped as an add-on. It is the wrong Home now. People who paste five watch URLs should not have to discover a mode.

The new p2 has one field. Whitespace or commas split it. One URL goes through ValidateURL. Two to twenty go through AnalyzeBatchURLs. A playlist URL is still a playlist. The 2–20 cap stays. Playlist URLs still do not belong inside a batch.

Why the icon fails

The control is unlabeled except for a tooltip. Active state is a tinted square next to Analyze. That is a developer affordance. The paste already contains the answer.

3. A video is a dock, not a form

After Analyze, main builds a workspace: a thumb, a title block, a Choose Download column, a radio list of every plan, a complete-file essay, then a save bar. That is all true. It is also a lot of chrome for one decision. Most people pick Recommended and Add to Queue.

The new p2 puts identity, Video / Audio, and the plan chips on one dock. Size and codec sit on a disclosure row. Opening it reveals the full plan list and the extras main already has: subtitles, extra .srt, artwork and chapters as a note, title and channel, the FFmpeg warning. The save footer keeps Change… and Add to Queue.

Backend plans still author the chips. The UI does not invent 1080p when the analysis returned something else. Review the playlist instead stays when the original link contained both.

4. After Analyze, the list owns the height

Main already pins the analyze bar and lets the playlist fill. That is the correct layout, and the old p2 prototype threw it away by keeping the field vertically centered. The new p2 does not repeat that. Empty Home is centered. The moment a dock exists, the field pins and the episode list takes leftover height.

What changes is the chrome around that list. Identity and policy collapse into the dock. Coverage, 21 of 24 reach 1080p, sits on the disclosure line. Select all, None, range, and search stay in the list header because a 24-row review is a selection job, not a caption.

Primary copy is Start N. Unavailable rows stay visible and dimmed. Indexes do not renumber after a filter.

5. The paste decides. The review stays honest.

Main will not start a batch until each line is Ready, Duplicate, Invalid, or Analysis failed. That is the product. The old p2 prototype showed five titles and Admit 5, including a seeded 429 that looked ready. The new p2 does not get to be that pretty.

After Analyze, the dock is a count tile and one policy. The disclosure is the existing review: line number, thumb, title or raw input, status chip, reason. N on Start N is the ready count. Expired token copy stays. Edit URLs puts the text back in the one field.

Video extras remain the Settings default, shown as a note, not a second editor. That is already how collection admission works.

6. A failed Analyze stays on Home

Unsupported and private links already fail with a dialog on main. That is honest, and it also yanks the user off the field they just used. The new p2 keeps the field and paints an error slot under it. Heading and message still come from the backend. Typing in the field clears the slot.

A watch URL that also contains a playlist is not an error. It stays the existing modal: this video only, or the full playlist. After a video choice, Review the playlist instead remains on the dock.

Do not add a try-chip that promises a private download. A chip that demonstrates the unsupported error is fine. Sign-in is out of scope.

7. After add, offer the queue, then reset

Main turns the primary button into Added to Queue and fires a banner. That is clear and a little sticky. The new p2 can keep the button state for the same identity, and also put a quiet line under the field: added, with a link to Queue. Changing the URL still clears analysis. Three seconds later the empty landing can return if the field is blank.

Do not navigate to Queue automatically. The person may want a second paste.

What this p2 must not drop

The dock is a restyle of admission, not a new product. If a later pass gets prettier by deleting one of these, it has left the app.

  • Analyze before anything enters the queue.
  • Change… on every save bar. The path is not a caption.
  • Backend-authored plans, capabilities, and tokens.
  • Batch line status, the 2–20 cap, and the 500-entry playlist cap.
  • The video-and-playlist modal, plus Review the playlist instead.
  • Subtitle, extra .srt, and title and channel extras in the disclosure.
  • Artwork and chapters always on for video. No toggle that pretends otherwise.
  • FFmpeg gates on complete video and on MP3. Original audio can still queue without it.
